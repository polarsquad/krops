# Proposals

Design proposals and architecture discussions that are not yet decided or
implemented. A proposal is reviewed as a pull request; once accepted it is
split into sub-issues, and the resulting behavior is documented in the regular
`docs/` pages. Each proposal states its status at the top and links its
tracking issue.

| Proposal | Status | Tracking issue |
|----------|--------|----------------|
| [Crossplane on the management cluster](crossplane-management-cluster.md) | draft | [#313](https://github.com/polarsquad/krops/issues/313) |
| [Air-gap bundle update: in-place, blue/green, recreate](airgap-update-architectures.md) | draft | [#369](https://github.com/polarsquad/krops/issues/369) |

Proposals link to other repository files with absolute GitHub URLs, because
the documentation site assembles this folder separately from the top-level
pages.
